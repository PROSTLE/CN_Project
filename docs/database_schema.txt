------------------------------------------------------------------------------
0. DESIGN PRINCIPLES
------------------------------------------------------------------------------
  - Postgres is the system of record. Kernel maps are the enforcement truth;
    the DB keeps a MIRROR (enforcement_entries) for UI/audit, reconciled by
    the agent.
  - All tunables live in DB tables with version + provenance (which
    validation run produced them). Nothing learned is hardcoded.
  - Ledger tables are append-only: UPDATE/DELETE blocked by trigger and by
    role grants. (Demo step D5 deliberately tampers as DB superuser to show
    the verifier catches it.)
  - Raw IPs/ports are stored for enforcement and audit ONLY; they are never
    columns of any training feature table [SRC hygiene].
  - Timestamps: TIMESTAMPTZ, UTC. IDs: BIGSERIAL for high-volume tables, UUID
    for entities referenced across services [PROPOSED].
  - Migrations: Alembic (Python) [PROPOSED]. File: db/migrations/.

2. REFERENCE / CONFIG TABLES
------------------------------------------------------------------------------
2.1 feature_groups                                   [SRC section 2]
  group_id        TEXT PK              -- 'G1'..'G14'
  name            TEXT NOT NULL        -- e.g. 'TCP-flag behaviour'
  description     TEXT
  display_order   SMALLINT
  Seed rows (from ideation, not invented):
    G1 TCP-flag behaviour (SYN/ACK/FIN/RST ratios) | G2 Packet-size distribution
    G3 Inter-arrival timing | G4 Rate (pps/bps) | G5 Port fan-out
    G6 Host fan-out | G7 Payload-independent length stats
    G8 Connection state | G9 Direction/asymmetry | G10 Source history
    G11 Threat-intel/reputation | G12 Flow duration/lifecycle
    G13 Protocol mix | G14 List membership (black/white)

2.2 features
  feature_name        TEXT PK
  group_id            TEXT FK -> feature_groups NOT NULL
  source              TEXT CHECK IN ('FLOW','SEQUENCE_CHANNEL','CONTEXT')
  kernel_realizable   BOOLEAN NOT NULL  -- true only if DP computes it
  kernel_map_field    TEXT NULL         -- which BPF counter backs it
  unit                TEXT
  dtype               TEXT
  is_identity         BOOLEAN DEFAULT false -- IP/port; must be false for any
                                            -- feature used in training
  CHECK (NOT is_identity OR NOT kernel_realizable OR true)  -- doc only
  NOTE: the rule compiler may ONLY reference rows with kernel_realizable=true.

2.3 class_labels
  class_id SMALLINT PK, name TEXT UNIQUE, is_attack BOOLEAN NOT NULL

2.4 dataset_label_map
  dataset TEXT, raw_label TEXT, class_id FK, PRIMARY KEY(dataset, raw_label)

2.5 config_versions  (all [LEARNED] / tunable parameters, versioned)
  config_id        UUID PK
  created_at       TIMESTAMPTZ
  created_by       TEXT
  source_run_id    UUID FK -> experiment_runs NULL  -- provenance
  ecs_k            SMALLINT     [LEARNED]
  ecs_alpha        REAL         [LEARNED] CHECK 0..1
  tau_hi           REAL         [LEARNED]
  tau_lo           REAL         [LEARNED] CHECK (tau_lo < tau_hi)
  fpr_budget       REAL         (policy input for tau learning)
  aci_gamma        REAL
  aci_alpha_target REAL
  checkpoints      SMALLINT[]   -- default from SRC: {8,16,32}
  seq_len_n        SMALLINT     -- SRC: 32
  ig_steps         SMALLINT     -- SRC: ~16
  rule_fidelity_min_agreement REAL  [LEARNED/policy]
  rule_fidelity_max_fpr       REAL  [LEARNED/policy]
  canary_seconds              INT
  rule_default_ttl_seconds    INT
  rollback_fp_limit           REAL
  quarantine_rate_pps         INT   -- token bucket rate for quarantine
  quarantine_burst            INT
  policy                      policy_mode
  ledger_batch_size           INT
  ledger_batch_max_seconds    INT
  is_active                   BOOLEAN  -- exactly one active (partial unique idx)
  raw                          JSONB   -- full YAML snapshot
  sha256                       TEXT    -- hash of raw, logged to ledger

2.6 safety_allowlist   [SRC section 6]
  id SERIAL PK, cidr CIDR NULL, proto TEXT, port INT, description TEXT,
  immutable BOOLEAN DEFAULT true
  Loaded into the kernel allow map at agent start. Rule compiler and API
  refuse any rule/verdict that would match these entries.

2.7 users [PROPOSED]
  user_id UUID PK, username TEXT UNIQUE, password_hash TEXT (argon2),

2.9 ui_audit_log [PROPOSED]
  id BIGSERIAL, user_id FK, action TEXT, target_type TEXT, target_id TEXT,
  payload JSONB, at TIMESTAMPTZ
  (records accept/reject rule, verdicts, policy change, export, etc.)

7. LEDGER & ATTESTATION (Invention 4)  - APPEND-ONLY
------------------------------------------------------------------------------
7.1 ledger_entries
  seq           BIGINT PK (gapless, assigned by single writer)
  decision_id   BIGINT FK decisions UNIQUE
  payload       JSONB  -- canonical: {flow_id, feature_hash, model_set_id,
                       --  decision, conformal_set, ecs, topk_groups,
                       --  rule_id, timestamp}  [SRC field list]
  payload_canon BYTEA  -- exact canonical bytes (RFC 8785 JCS) [PROPOSED]
  prev_hash     BYTEA  -- 32 bytes; genesis = 32 zero bytes
  entry_hash    BYTEA  -- SHA-256(prev_hash || payload_canon)
  batch_id      UUID FK merkle_batches NULL
  appended_at   TIMESTAMPTZ
  TRIGGER ledger_no_update: BEFORE UPDATE OR DELETE -> RAISE EXCEPTION.
  GRANT: app role has INSERT, SELECT only.

7.2 merkle_batches
  batch_id      UUID PK
  first_seq     BIGINT, last_seq BIGINT
  merkle_root   BYTEA
  signature     BYTEA   -- Ed25519 over (root || first_seq || last_seq ||
                        --  prev_batch_root || pcr_digest)
  key_id        TEXT
  prev_batch_id UUID FK NULL
  tpm_quote     BYTEA   -- TPMS_ATTEST blob
  tpm_quote_sig BYTEA
  pcr_index     SMALLINT
  pcr_value     BYTEA
  model_set_id  FK, ruleset_id FK, config_id FK
  signed_at     TIMESTAMPTZ

7.3 pcr_events  (measurement log, like a TPM event log)

7.4 signing_keys

11. KERNEL BPF MAPS (enforcement table + counters) [SRC section 6]
------------------------------------------------------------------------------
  Name              Type                Key                     Value
  flow_verdict      LRU_HASH            5-tuple                 {action, rate_pps,
                                                                 burst, expires_ns}
  src_verdict       LRU_HASH            src IPv4                {action, rate_pps,
                                                                 burst, expires_ns}
  prefix_list       LPM_TRIE            {prefixlen, ipv4}       {action: allow/deny}
  safety_allow      HASH                {proto, port} / cidr    {flag}  (checked FIRST)
  rules_a, rules_b  ARRAY[MAX_RULES]    slot                    {n_pred, preds[...],
                                                                 action, mode(enforce|
                                                                 log_only), rule_tag,
                                                                 expires_ns}
  rules_active      ARRAY[1]            0                       {active_index 0/1}
  token_bucket      LRU_HASH            {key_type, key}         {tokens, last_ns}
  flow_stats        LRU_HASH            5-tuple                 {pkts, bytes, syn, ack,
                                                                 fin, rst, first_ns,
                                                                 last_ns, emitted_cnt}
  src_stats         LRU_HASH            src IPv4                {syn_cnt, pkts, bytes,
                                                                 window_start_ns,
                                                                 port_bitmap/bloom,
                                                                 host_sketch}
  canary_counters   PERCPU_ARRAY        slot                    {would_drop, matched}
  events            RINGBUF             -                       packet_record /
                                                                 flow_summary
  packet_record = {flow 5-tuple, pkt_index, size, direction, tcp_flags,
                   delta_t_ns, ts_ns}
  MAX_RULES, map sizes, window lengths: compile-time constants injected from
  config at build (not literals scattered in code).
  Predicate features available in kernel = exactly the features rows with
  kernel_realizable=true; the agent publishes this list at startup and the
  brain checks it (single source of truth).
